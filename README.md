# アジト防衛演習室

## アイデア(ユーザーの原文)

公開済みの情報屋アジトのUIと機能の流れを安全に模した、ローカル専用の大学生向けセキュリティ演習アプリ。テストデータと初期状態へ戻す仕組みを備え、実アプリ・本番DB・認証情報・公開環境とは完全に分離する。

## 現在の状態

- 2026-11-06: 情報屋アジトの画面・機能構成を別リポジトリへ複製し、Cloudflare/D1/公開用コマンドを除去。localhost専用・専用SQLite DB・専用Cookie名に分離した。
- 2026-11-06: `npm run db:reset` で架空アカウントと投稿を復元できる。認可を題材にした意図的な演習用ルートを追加。対象はこの演習室だけで、実アプリや公開URLには絶対に使わない。

## 使い方

```powershell
npm install
npm run db:reset
npm run dev
```

`http://127.0.0.1:3227` を開く。お試しIDは `kage` / `mika` / `ren` / `sora`、パスワードはすべて `seed-pass-1234`。

## 演習の境界

- 対象はこのリポジトリと localhost のみ。公開済みアジト、第三者サービス、実在アカウントには試さない。
- 初期化は `npm run db:reset`。専用DB以外は処理を拒否する。
- 課題と修正の確認方法は [docs/exercises.md](docs/exercises.md) を参照。

## 開発

- 一括検証: `pwsh -NoProfile -File scripts/codex-verify.ps1`
