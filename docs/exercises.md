# 防衛演習の規則

このリポジトリと `http://127.0.0.1:3227` だけが対象です。公開済みの情報屋アジト、第三者のサービス、実在のアカウントやデータは対象にしません。

課題を見つけたら、影響を説明し、修正し、同じ確認が通らなくなったことをテストで示してください。`npm run db:reset` で架空データを初期状態に戻せます。

## 第一課題: 認可

`/api/training/dossiers/[id]` は、この演習環境でだけ有効な意図的な認可漏れです。ログイン確認と、封をした投稿を読む権限の確認をどこへ置くべきか検討し、修正後の回帰テストを追加してください。
